# 🎯 Tic-Tac-Toe Analysis Project

This project simulates AI gameplay in a classic Tic-Tac-Toe environment using the **minimax algorithm**,  
exploring how **intentional randomness** affects game outcomes and decision-making logic.

---

## 📋 Overview

- **Goal**: Investigate how imperfect AI decisions influence game results in a simple rule-based environment.
- **Scope**: Introduce random moves and variable prediction depth to observe how AIs perform under controlled uncertainty.
- **Tools**: Python, pandas, matplotlib, minimax algorithm

> ⚠️ **Note**  
> This project was conducted purely for simulation and analysis purposes.  
> All results were generated in a local test environment using code-based simulations.

---

## 🛠️ Testing Environment

| Component         | Details                        |
|------------------|--------------------------------|
| Environment      | Visual Script Code              |
| Language         | Python 3.10                     |
| Visualization    | matplotlib, pandas              |
| Algorithm        | Minimax (custom depth + random) |
| Game Type        | Tic-Tac-Toe (CLI-based)         |

---

## 🔍 Key Highlights

- 10% probability of **random moves** added to simulate imperfect decision-making.
- Prediction **depth randomized (1–4)** to simulate variable AI strategy levels.
- 5 sets × 50 rounds of matches were run, with **O vs X performance recorded**.
- Compared results with fully optimized (perfect) AI play (resulted in full draws).
- Plotted win/draw distributions using matplotlib.
